# 第一部分：系统级分类（Domain Level）—— 按整车五大域划分

> 一级分类按控制器在整车中的位置划分为 5 大域；二级分类（子系统）按域内功能与典型控制器进一步细分。

## 1. 动力域 Powertrain
- 功能：动力输出、扭矩分配和能源管理
- 典型系统/控制器：整车控制器 VCU、电机控制器、电池管理 BMS、充电管理

| 二级分类 | 涵盖内容 | 现有方案条目 |
| --- | --- | --- |
| 整车控制器（VCU） | 整车能量管理与扭矩分配 | （待补充） |
| 电机控制器 / 电驱系统 | 牵引逆变器、辅助逆变器 | 电动汽车辅助逆变器；适用于建筑、商用和农用车辆的高压辅助应用；电动汽车牵引逆变器；牵引逆变器(商用车)；牵引逆变器(两轮车和三轮车) |
| 电池管理系统（BMS） | 电池监控、均衡、保护与通信 | 汽车电池监控和平衡；汽车电池控制单元(BCU)；汽车电池隔离通信；汽车12V-24V电池管理系统(BMS)；汽车48V电池管理系统(BMS)；汽车电池管理系统(BMS)-高电压；汽车电池组监控；汽车电池护照和事件记录；汽车电池保护和断开连接；汽车电流传感和库仑计量；BMS(两轮车和三轮车) |
| 充电与电源转换 | 车载充电 OBC、DC-DC、充电连接 | 用于电动汽车的高压DC-DC 转换器；高压DC-DC转换器(商用车)；电动汽车充电连接；车载充电(电动商用车)；车载充电(OBC)；电动两轮车和三轮车的车载充电 (OBC)解决方案；区域 DC-DC 转换器 48V-12V |
| 燃料电池系统（FCEV） | 燃料电池控制与电堆辅助 | 燃料电池控制单元(FCCU)；燃料电池DC-DC升压转换器；燃料电池电动空气压缩机 |
| 热管理（泵与风扇） | 电池/电机热管理循环 | 汽车电动泵和风扇 12V；汽车电动泵和风扇 48V |

## 2. 底盘域 Chassis
- 功能：转向、制动、悬架及车辆姿态控制
- 典型系统/控制器：电动助力转向 EPS、车身稳定控制 ESC、电子驻车 EPB、悬架控制

| 二级分类 | 涵盖内容 | 现有方案条目 |
| --- | --- | --- |
| 转向系统 | 电动助力转向、线控转向 | 电动助力转向(EPS)；24v电子助力转向带主动转向；线控转向 |
| 制动系统 | 制动助力、驻车、稳定控制 | 电动制动助力器；电动驻车制动器；机电制动系统(EMB)；电子稳定控制 |
| 悬架系统 | 悬架控制、主动悬架 | （待补充） |

## 3. 车身域 Body
- 功能：车身电器、舒适和便利功能
- 典型系统/控制器：车身控制器 BCM、车门、车窗、灯光、雨刮、门锁

| 二级分类 | 涵盖内容 | 现有方案条目 |
| --- | --- | --- |
| 车身控制模块（BCM） | 中央车身控制、集成网关 | 汽车车身控制模块 (BCM)；带集成网关的车身控制模块 (BCM) |
| 车门与门锁系统 | 门控、门禁、闭锁、后视镜 | 门控模块；智能汽车门禁；智能闭锁系统；去中心化的镜子模块 |
| 车窗与车顶系统 | 车窗升降、天窗、车顶控制 | 智能车窗升降模块；带内部和环境光控制功能的车顶控制模块 |
| 灯光系统 | 内外饰照明 | LED 驱动器（两轮车和三轮车） |
| 雨刮与辅助系统 | 雨刮、辅助电机、液压/气动管理 | 挡风玻璃雨刮器系统；辅助电机控制-12VDC 电机控制器；CAV 液压管理系统；CAV 气动管理系统 |
| 座椅系统 | 座椅控制、舒适度调节 | 座椅控制模块；座椅舒适度模块 |
| 汽车配电系统 | 一次/二次配电 | 汽车一次配电单元；汽车二次配电单元 |

## 4. 座舱域 Cockpit
- 功能：人机交互、信息显示和娱乐
- 典型系统/控制器：中控车机、仪表、HUD、音响、语音交互

| 二级分类 | 涵盖内容 | 现有方案条目 |
| --- | --- | --- |
| 信息娱乐主机（IVI） | 中控车机、车载连接 | 汽车 USB 供电 - 主机；汽车 USB Type-C 供电 （PD）；USB-C 后座娱乐系统 |
| 仪表与显示 | 仪表、HUD | 智能仪表盘（两轮车和三轮车） |
| 舱内无线充电 | 手机无线充电 | 全套无线充电系统 (WLC)-集成；无线充电系统 (WLC)-离散式 |
| 音响与语音交互 | 音响、语音助手 | （待补充） |

- 功能：环境感知、驾驶决策和辅助驾驶
- 典型系统/控制器：摄像头/雷达处理、感知融合、ACC、车道保持、自动泊车

| 智能驾驶域控制器 | 感知融合、决策规划、ACC/车道保持/自动泊车 | （待补充） |
